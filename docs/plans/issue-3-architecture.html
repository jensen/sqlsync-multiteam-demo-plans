Labels Feature Architecture
RENDERER (React UI)
1 User clicks label picker
2 Select labels (multi-select)
3 Dispatch AddIssueLabel mutation
SQLSync Mutation
MAIN PROCESS (Rust Reducer)
4 Deserialize mutation from WASM
5 Execute SQL: INSERT into issue_labels
6 Return success to SQLSync
Broadcast
SQLSYNC DB (SQLite)
7 Persist to issue_labels table
8 Broadcast change to all clients
9 UI re-renders with new labels
Database Schema (New Tables)
Table Columns Purpose
labels id (PK), name, color, team_id, created_at
UNIQUE(name, team_id) 		Label definitions per team
issue_labels issue_id (FK), label_id (FK), created_at
PRIMARY KEY (issue_id, label_id)
ON DELETE CASCADE 		Many-to-many junction table
New Mutation Variants (Rust Enum)
Mutation Parameters SQL Operation
AddLabel id, name, color, team_id INSERT into labels
UpdateLabel id, name?, color? UPDATE labels SET ...
RemoveLabel id DELETE from labels (CASCADE)
AddIssueLabel issue_id, label_id INSERT into issue_labels
RemoveIssueLabel issue_id, label_id DELETE from issue_labels
