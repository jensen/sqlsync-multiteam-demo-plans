Step-by-Step Breakdown

1 User action: User opens issue details and clicks the "Add Label" button in the label picker
2 UI component: LabelPicker displays available labels for the team with color-coded chips
3 State update: User selects labels → IssueStore.addIssueLabel(issueId, labelId) is called
4 Reducer execution: Rust reducer receives AddIssueLabel { issue_id, label_id } mutation via WASM bridge
5 Database operation: Reducer executes SQL: INSERT INTO issue_labels (issue_id, label_id, created_at) VALUES (?, ?, ?)
6 Sync broadcast: SQLSync detects change to issue_labels table and broadcasts to all connected clients
7 UI update: All clients receive change notification → LabelChip components render with new label data
